# 六类概率融合验证

## 验证对象

原最佳模型：端到端 DenseNet-121 + Clinical Mamba，最佳 epoch 50。

概率规则来自 `predict_proba.py`：两个三分类头分别 softmax，再将六种合法 `(type, pattern)` 组合的乘积重新归一化。

## 直接测试集推理结果

| 决策方法 | Accuracy | Weighted F1 | Macro F1 |
|---|---:|---:|---:|
| 原双头独立 argmax | 67.25% | 63.88% | 47.22% |
| 六类合法概率融合 argmax | 67.25% | 63.88% | 47.22% |

- 测试样本：171
- 非法双头组合：0
- 六类融合后发生变化的预测：0
- 平均 top-1 概率：93.44%
- Multiclass NLL：2.1162
- Multiclass Brier：0.6104

## 与已有模型对比

| 模型 | Accuracy | Weighted F1 | Macro F1 |
|---|---:|---:|---:|
| ViT 静态基线 | 59.65% | 53.34% | 28.78% |
| Swin-B 静态基线 | 63.16% | 52.72% | 31.39% |
| DenseNet-121 静态基线 | 66.08% | 60.68% | 43.38% |
| MobileNet + Clinical Mamba（冻结） | 61.40% | 54.74% | 29.45% |
| MobileNet + Clinical Mamba + Attention（冻结） | 60.23% | 54.14% | 31.82% |
| DenseNet-121 + Clinical Mamba（端到端） | **67.25%** | **63.88%** | **47.22%** |
| 上一行 + 六类概率融合 | **67.25%** | **63.88%** | **47.22%** |

## 结论

1. 该工具不是新的可训练分类头，而是推理阶段的合法类别约束和概率导出规则。
2. 原最佳模型在测试集上没有产生非法 type-pattern 组合，因此该规则没有改变预测或分类指标。
3. 该规则仍值得保留用于临床部署：输出六类归一化概率、top-k候选和置信度。
4. 当前概率明显过度自信：平均置信度93.44%，但准确率67.25%。下一步更有价值的是在验证集上拟合温度缩放，改善概率校准；不能预期它提升Accuracy。
